# SureshKrishna M — Digital Resume

A responsive, accessible digital resume built with semantic HTML, modern CSS, and lightweight JavaScript. It is a static site with no build step or runtime dependencies, so it can be hosted directly on GitHub Pages.

The resume content is transcribed from [`assets/resume.pdf`](./assets/resume.pdf). The PDF is also available from the **Download PDF** button at the top of the site.

## Preview locally

Open `index.html` in a browser, or run a local static file server from the project root:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Open the Pages URL shown in the repository settings after deployment completes.

This site includes contact, visa, and availability details from the resume. GitHub Pages sites are publicly accessible.
